# Tarka Programming Language

**Tarka v0.5 — Experimental Interpreter**

Tarka is an experimental interpreted programming language with Sanskrit-inspired keywords written using English transliteration.

The goal of Tarka is to develop a simple, expressive, general-purpose programming language, with future plans for AI and chatbot development capabilities.

## Current Features

- Integer, Float, String, Boolean and Null data types
- Variables and reassignment
- Arithmetic and comparison operators
- Logical operators
- If/Else conditions
- For and While loops
- Break and Continue
- Functions and parameters
- Return statements and recursion
- Lists and Dictionaries
- Indexing and updating collections
- Input and Output
- Basic error reporting

## Example Program

```tarka
mana name = "Tarka"

kriya greet(person) {
    mudraya "Namaste " + person
}

greet(name)
```

## Running Tarka

Requirements: Python 3

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate into the project:

```bash
cd Tarka
```

Run the interpreter:

```bash
python tarka.py
```
